# 02_外语词汇表 · 需求规格说明书 v2.0

> 第一波次交付物（2026-08-23）· 基于基线能力清单（03 号文档）+ 顶尖标准对标表（02 号文档）
> 版本 v2.0（2026-08-23 · 基于波次 2 方案更新）：需求完整、标准明确、可落地；已升级 v2.0

## 1. 项目定位

**原著语境、全字段信息、多维度筛选、精美渲染**的外语词汇表制作工具：PDF 书籍导入 → 全书词汇提取 → 全字段词条 → 附件产物 → 多格式导出，MCP 插件化接入 PAEG 生态。

### REQ-V-A 输入与清洗

| ID | 需求 | 验收标准 | 优先级 |
|---|---|---|---|
| V-A1 | PDF 书籍导入 | PDF 解析可用 | P0 |
