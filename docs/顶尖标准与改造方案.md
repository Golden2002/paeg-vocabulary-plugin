# 词汇表工具「顶尖水平」可执行标准与改造方案（调研 + 差距分析）

> 调研来源：语言学习工具（LingQ/Readlang/Lute/Anki/DuoCards/WordUp/FluentU/Language Reactor）+ 电子词典（欧路/GoldenDict/mdict）+ AI 词汇工具 + 网页设计。调研时间 2026-08-31。

## 一、现状（已达标，保留升级）

- 词库：ecdict(77万词, BNC/COCA/Collins/Oxford/exchange/tag) + CMU 音标 + CEFR/Oxford 分级 + kaikki 学科术语（多源聚合 S1 ✅）
- LLM：书名识别 / 关键术语 / 词条结构化补全（词源·词素·多义项·例句·搭配）/ 深度解读
- 交付：HTML/PDF/docx + 7 附件 + 交互式单页（分页/搜索/点击展开/SRS 三态）
- 点击查词阅读器 / 词频·风格·学习价值统计

## 二、顶尖水平可执行标准（P0 必做 / P1 应做 / P2 可选）

### P0（必做，本轮或下轮补齐）
| # | 标准 | 验收口径 |
|---|---|---|
| P0-1 | 发音音频 | 词条旁点击即读（Web Speech API / TTS），✅已落地 |
| P0-2 | 深色模式 | `data-theme=dark` + 切换按钮 + 跟随系统 prefers-color-scheme + localStorage 记忆；对比 ≥4.5:1 |
| P0-3 | 键盘导航 | `←/→` 翻页；`1/2/3` 或 `j/k` 标词条状态；`d` 切深色；全程可键盘操作 |
| P0-4 | 排版规范 | 正文字号 16–18px、行高 1.5–1.75、行长 ≤80ch、留白充足 |
| P0-5 | 动画过渡 | 卡片展开/收起、hover 用 transform/opacity 150–300ms；尊重 prefers-reduced-motion |
| P0-6 | SRS 四键评分 | Again/Hard/Good/Easy 四键 + SM-2 真调度（间隔/到期队列），非三态 |
| P0-7 | 词频内联可视化 | 词条旁水平条形图（弃词云）；复习负荷 7 天柱状图；进度热力图 |
| P0-8 | 全文状态着色 | 阅读器正文内蓝/黄/白三态着色（LingQ 式），非仅点击查词 |
| P0-9 | 导出 Anki | 生词/进度导出 Anki 可导入格式（TSV/apkg） |
| P0-10 | 跨书术语库 + 原形归并 | 多书共享术语库；Parent/Child 原形归并（Lute 式） |

### P1（应做）
- 划词取词 + 剪贴板取词（GoldenDict 式）、词典分组聚合呈现
- mdx/mdd 标准词典导入（mdict-js / @goworks/mdict 预索引）
- WordNet 语义网络（同义/反义/上下位）
- 分级例句（例句标 CEFR，静态资源命中优先、LLM 兜底）
- LLM 深度解读改「渐进披露」（tooltip/展开，避免打断阅读）
- 复习负荷可视化（未来 7 天到期柱状图）

### P2（可选）
- AI 对话/练习生成器（词条问答/填空）
- 语音评测（发音评分）
- 词根词缀词族可跳转

## 三、设计口径（调研结论）

- 排版：正文 16–18px / 行高 1.5–1.75 / 行长 ≤80ch
- 深色：`#121212` 系（非纯黑）+ 文本对比 ≥4.5:1
- 动画：150–300ms 只用 transform/opacity + `prefers-reduced-motion` 降级
- 可视化：词频用水平条形图（弃词云）；进度用 GitHub 日历热力图；复习负荷用未来 7 天到期柱状图

## 四、最值得抄的 4 个点

1. **LingQ**：全文蓝/黄/白三态着色（词汇状态可视化在正文里，而非独立表）
2. **Lute**：跨书术语库 + Parent/Child 原形归并 + 纯键盘阅读
3. **Readlang**：词频在正文内分级高亮 + 侧栏生词本带上下文
4. **Anki**：四键评分（Again/Hard/Good/Easy）+ 真调度（SM-2/FSRS + 间隔 + 到期队列）

## 五、实施路线

- 本轮（P0-1~P0-5 落地）：发音、深色模式、键盘导航、排版、动画 —— 交互式单页改造
- 下轮（P0-6~P0-10）：SRS 四键调度、词频内联、全文着色、Anki 导出、跨书术语库
- 参考库 URL 见各工具 README（LingQ/Readlang/Lute/Anki/欧路/mdict-js/ts-fsrs 等）
