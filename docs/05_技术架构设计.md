# 02_外语词汇表 · 技术架构设计

> 波次 2 交付物（2026-08-23）· 依据：基线能力清单（50 项 A-E 域）+ 顶尖标准对标表（V-01~V-08）
> 正式项目根目录：`14.3_paeg-vocabulary-plugin\`（本设计为波次 3 开发蓝图，基线 50 项能力原样保留）

## 1. 总体架构（四层 + MCP 标准件）

```
┌───────────────────────────────────────────────────────────────┐
│ L1 接口层                                                       │
│  Flask API（基线 web_api 升级）+ 导入→筛选→生成→导出 闭环         │
├───────────────────────────────────────────────────────────────┤
│ L2 服务层（管线编排）                                            │
│  PipelineService: 导入→清洗→提取→词条富化→产物→渲染→导出          │
│  （基线 18 项 A 管线能力沉淀为可编排服务）                         │
├───────────────────────────────────────────────────────────────┤
│ L3 内核层（基线 100% 保留 + 升级点）                              │
│  extractor（提取/去重/停用词/词频/词性/难度）                     │
│  enrich（IPA/释义/词源/例句/搭配——cmudict/domain/kaikki 等）      │
│  artifacts（词频榜/覆盖率/句式统计/风格分析/学习价值）             │
│  render（生命现象学 CSS 模板 / HTML/PDF/Markdown）               │
│  languages（en/de/fr/es 多语种 + 扩展接口）                       │
├───────────────────────────────────────────────────────────────┤
│ L4 数据层                                                       │
│  cmudict.dict│cefr_words│oxford3000│kaikki_topic│level_matrix    │
│  +（升级）ecdict.csv 接线 / OCR 图像识别接口                      │
├───────────────────────────────────────────────────────────────┤
│ MCP Server（基线 11 工具 → 升级三原语完整）                       │
└───────────────────────────────────────────────────────────────┘
```

**设计原则**：基线 A-E 域 50 项 100% 保留（含三项诚实标注对应升级点：①Word 导出新增 ②图像 OCR 新增可插拔接口 ③ecdict 等数据接线）；渲染模板原样复用（Bell Jar CSS 禁止简化版）。

## 2. 模块划分（能力映射）

| 模块 | 职责 | 能力来源 | 新增/保留 |
|---|---|---|---|
| `extractor`（基线） | 提取/去重/停用词/词频/词性/难度筛选 | A 管线 18 项 | 保留 |
| `ocr_fix`（基线） | 文本层 OCR 断裂修复（连字符/拼接/编码） | A-OCR | 保留 |
| `ocr_image` | 图像 OCR 可插拔接口（tesseract 等，缺失降级） | V-01 | 新增 |
| `enrich`（基线） | IPA/释义/词源/例句/搭配（8 类词库消费） | B 词库 12 项 | 保留 |
| `ecdict_bridge` | ecdict.csv(65MB)/cefrj/octanove 数据接线（基线已下载未引用） | V-02 | 新增（补接线） |
| `artifacts`（基线+扩展） | 词频榜/覆盖率/句式统计/风格分析/学习价值 | C 产物 | 保留+补齐 |
| `render`（基线） | 生命现象学 CSS 模板/HTML/PDF/Markdown | C 渲染 8 项 | 保留 |
| `export_docx` | Word(.docx) 导出引擎（基线缺失项） | V-05 | 新增 |
| `languages`（基线） | en/de/fr/es + 语种扩展接口 | E 多语种 | 保留 |
| `mcp_server.py`（基线） | MCP 11 工具 → 升级三原语 | D 生态 | 保留+升级 |
| `web/`（基线） | Flask web + 23 档 preset → 导入→筛选→生成→导出闭环 | V-07 | 保留+升级 |

## 3. 核心接口定义

```
POST /api/vocab/build            # 全书词表构建（管线入口）
  in:  {book_path, lang, filters:{freq, pos, cefr}, fields:[ipa,def,ety,example,colloc]}
  out: {book_id, stats:{total, unique, filtered}, progress}
GET  /api/vocab/entries          # 词条查询（分页/筛选）
GET  /api/vocab/artifacts        # 词频榜/句式统计/风格分析/学习价值
POST /api/vocab/render           # 渲染（模板/格式：pdf|docx|md|html）
POST /api/vocab/import           # PDF/文本导入（含 OCR 修复）
```

## 4. MCP 插件结构（顶尖标准）

| 原语 | 名称 | 说明 |
|---|---|---|
| Tools | `vocab_build(book_path, lang, filters)` | 全书词表构建（基线 build 工具升级） |
| Tools | `vocab_lookup(word, lang)` | 单词全字段查询（基线 lookup 工具） |
| Tools | `vocab_artifacts(book_id)` | 附件产物生成 |
| Tools | `vocab_render(book_id, fmt)` | 渲染导出 |
| Resources | `vocab_books://{id}` | 已建词表库 |
| Resources | `vocab_dictionaries://list` | 词库数据源状态（cmudict/domain/kaikki…） |
| Prompts | `vocab_build_workflow` | 构建工作流模板 |
| Prompts | `vocab_render` | 渲染模板说明 |

## 5. 数据模型

```
VocabularyBook { id, lang, source, stats:{total, unique, filtered}, filters, entries[] }
WordEntry { word, ipa, defs:[{lang, meaning, sense}], etymology:{family, roots[], path},
            examples:[{text, source(原著页), sense_ref}], collocations[], freq, pos, cefr }
Artifacts { freq_rank[], colloc_stats, style_analysis, learning_value }
```

## 6. 部署形态

- 独立库（Python 3.10+）+ MCP Server（stdio）+ Flask Web（独立端口）
- 数据源可配置（`VOCAB_DATA_DIR`）；OCR 引擎可插拔（缺失降级文本层）
- 嵌入：被主 Agent 调用（上传 PDF → 生成词汇表 → 学习计划串联）

### 8.2 MCP 工具逐项保留 + 语种接口（Oracle 2.2-2）
- **基线 11 MCP 工具逐一保留/合并**：generate_vocabulary→vocab_build、lookup_word→vocab_lookup、list_languages→保留、list_generators→保留、validate_entry→保留、clean_examples→保留、extract_collocations→保留、quantile_of→保留、bank_coverage→保留、list_tools→保留（另 1 项按基线清单核对）
- **语种接口暴露**：`GET /api/vocab/languages` + MCP Resources `vocab_languages://list`（V-08 接口层可见）

### 8.3 ecdict_bridge 加载规格（Oracle 2.2-3）
- ecdict.csv(65MB)：**lazy 加载 + 分片索引**（首次查询时构建倒排，内存 ~200MB 上限）
- 许可与下载来源：复用 E01 download_wordbank.py（许可声明记录于 README）
- 加载失败降级：不阻塞构建，V-02 字段覆盖降级为可选（缺失字段置 null 标注）

### 8.4 导入入口一致性（Oracle 2.2-4）
- **决策**：`/api/vocab/import`（Web API 文件上传）为唯一导入入口；MCP 侧由宿主先完成文件落地（filesystem MCP）后调 `vocab_build(book_path)`——写死，避免双入口语义分裂

### 8.5 V-01 验收口径拆解（Oracle 2.2-5）
- **文本层 OCR 修复（基线 A02 五层管道）= 硬门**：断裂恢复率 ≥95%（测试集自基线 test_ocr_repair 扩展）
- **图像 OCR（ocr_image，tesseract 等可插拔）= 可选能力**：缺失降级不算未达标
